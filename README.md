# acme-shop

A tiny shop API (Node.js, no dependencies). It is the demo target repo for
[DocDesk](https://github.com/suhailult777/docdesk): a Switch agent answers
team questions from these docs.

## Run it locally

```bash
npm install
npm start
```

The server listens on port 3000. Set `SHOP_PORT` to use another port:

```bash
SHOP_PORT=8080 npm start
```
